# Requests

All request details belong here: client, location, appearance conditions, objective, client description, reward, deadline, and Tristitia's text. Manuscripts contain conversations, staging, and request availability notices only.

- Chapter 1.md: Chapter 1 timed requests.
- No Deadline Requests.md: one-time requests without countdowns, including when they appear.
- Recurring/Eurydica.md: repeatable work orders for Eurydica. Future bases get their own location file.

## Timing

A countdown begins the moment a request appears in the request list. Accepting it later does not restart the timer. A no-deadline request has no countdown.

For the Chapter 1 city requests (CH1-REQ-003 through CH1-REQ-007), unaccepted offers disappear after Chapter 1. Accepted requests remain completable afterward, subject to any remaining deadline. The two introductory requests' chapter cutoff is not yet specified.

## Manuscript notice

At the end of the branch that unlocks a request, write:

Request "Clinic Restock" [CH1-REQ-004] is now available.

This is a system notice, not spoken dialogue. Do not show it on a refusal branch or unlock the same one-time request again on repeat conversation.
