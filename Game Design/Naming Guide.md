# Naming Guide

Written 2026-09-28, when the placeholder and AI-generic names were replaced (owner-approved). Use it for every new character and place, including the Frontier cast.

## 1. The world's name roots

The owner's own names set the pattern. Pick the root that fits the person or place.

| Root | Owner's examples | Feel |
|---|---|---|
| **Latin (fantasy)** | Tristitia ("sorrow"), Valerie, Liliana | Old institutions, knights, scholars, nobles |
| **Greek** | Eurydica ("wide justice") | The land itself, old places, myth-flavoured people |
| **Germanic** | Fulker ("people's army"), Liliana Kessel | Crafts, trades, soldiers, guilds and merchants |
| **Wild West** | Elsie, Steady Mae | Frontier folk, plain-spoken people, nicknames with an epithet ("Steady Mae", "Iron Otto") |

## 2. Method

1. **Choose the root** by the character's world: trade, class, origin.
2. **Choose a name whose meaning echoes the role.** Occupational German surnames work especially well: Metzler (butcher), Riemer (strap maker), Esser (forge hearth).
3. **Avoid the overused AI-fantasy names:** Rowan, Mira, Aria, Elara, Lyra, Kael, Kai, Thorne, Vale, Ash, Reed, Flint, Frost, Brass, Seraphina, Aurelia, Evelyn, Silas, Corvin, Luna, Nova, Zephyr, and anything similar.
4. **Avoid clashes with the officers:** don't start a name with the same sound as an officer's name in the same scene (Elsie/Etta, Liliana/Livia).
5. **Record the meaning** in the character's roster entry.
